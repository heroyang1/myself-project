# 电子书模块说明

## 范围

本文合并了电子书模块当前相关的所有说明文档：
- 书签增强说明
- PDF 导入集成说明
- `opendataloader-pdf` 接入方案摘要

## 一、书签增强

- 新增书签高亮样式，提示当前区域已有书签。
- 同一章节内按位置百分比设置阈值，阈值内不允许新增重复书签，默认 2%。
- 书签支持用户自定义标签名；未填写时回退到章节标题。
- 删除书签增加二次确认。
- 书签新增入口改为“新增书签”拖拽块，拖到正文位置即可创建。
- 点击书签可跳转到对应章节位置，并同步滚动到视野中间。
- 图片章节逻辑保持不变。

## 二、漫画书籍级媒体类型

- 电子书模块新增书籍级媒体类型：`mediaType=1` 表示电子书，`mediaType=2` 表示漫画。
- 漫画和电子书的区别维护在 `osh_book.media_type`，不再依赖章节级类型判断。
- 资源编号继续使用后端 `ResourceCodePrefixEnum.BOOK`，不新增漫画专用资源编号前缀。
- 漫画章节图片按页存储到 MySQL 表 `osh_book_chapter_page`，核心字段包含 `book_id`、`chapter_id`、`page_no`、`image_url`、`width`、`height`、`file_size` 和 `checksum`。
- 章节详情接口在漫画书籍下返回 `pages`，前端阅读器按 `page_no` 进行长滚动漫画阅读。
- 漫画章节页保存采用“按章节物理清理旧页 + 按当前图片顺序重建”的策略；该表表示章节当前图片编排快照，不作为历史审计表。
- 保存时后端忽略前端传入的旧 `pageNo`，按数组顺序重新生成 1、2、3...，避免拖动图片后出现重复页码。
- `osh_book_chapter_page` 的当前页唯一约束应为 `uk_book_chapter_page(book_id, chapter_id, page_no, delete_flag)`。
- 电子书导入暂时只暴露占位接口 `/pc/book/import/ebook`，解析与落库流程后续再实现。
- 管理类接口补充 `@OshUserLevel` 等级注解，并保留原有权限表达式，避免放宽现有权限。
