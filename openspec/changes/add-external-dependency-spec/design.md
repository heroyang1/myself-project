# Design: add-external-dependency-spec

## 方案概览

纯文档变更：新建 `.harness/外部依赖规范.md`（三节结构，收拢课程 29~31 讲定稿细则），
并在 `CLAUDE.md` 第 3 层规范索引表追加一行指针。规范文档遵循"每节自答何时读、
全文只放结论与判据、示例可 grep"的写法；不复制红线正文，红线句仅标注"待 P6 决定晋升"。

## 现状分析

- 相关模块：无代码模块；涉及根 `CLAUDE.md` 与 `.harness/` 目录
- 相关类/接口：无
- 当前数据结构：无
- 当前配置：`CLAUDE.md` 现为 100 行（贴线），第 3 层已有 16 行索引；`.harness/` 下已有
  `ROUTING.md` 与 `candidate/README.md`，无外部依赖主题文档

```
.harness/外部依赖规范.md
├── 第 1 节 线程池：四参数显式声明 / 命名格式 <域>-call-%d /
```

## 兼容性

- 老接口是否保留：不适用（无接口变化）

## 测试计划

- 单元测试：不适用
- 集成测试：不适用
- 接口 smoke：不适用

  `Get-Content CLAUDE.md | Measure-Object -Line` ≤ 100；
