# Design: fix-current-compilation-regressions

## 方案概览

按编译错误逐项修复源码不一致和损坏文件，先处理公共依赖类，再处理调用点，循环编译直到 `backstage-system` 恢复可编译。

## 详细设计

### 修复顺序

1. 修复公共枚举与工具类中的语法/编码损坏
2. 修复调用方与公共类签名不一致问题
3. 重新编译并处理新增暴露的残余错误

### 兼容性

- 不改接口路径
- 不改数据库
- 不改权限
- 尽量保持原有业务语义

## 测试计划

- 以 Maven 编译为主验证
- 如需再暴露测试问题，后续增量处理
