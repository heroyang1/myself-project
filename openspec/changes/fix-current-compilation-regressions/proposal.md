# Proposal: fix-current-compilation-regressions

## 背景

当前仓库存在一批主源码编译错误，阻塞 `backstage-system` 模块编译和项目启动。  
从现有报错看，问题集中在公共枚举、工具类和少量调用点之间的源码不一致，以及个别文件被乱码破坏后的语法损坏。

## 目标

- 修复当前阻塞 `backstage-system` 编译的主源码错误。
- 优先恢复项目可编译、可启动状态。
- 改动范围仅限编译修复，不做无关重构。

## 非目标

- 本次不调整业务流程。
- 本次不做数据库结构变更。
- 本次不处理与编译无关的历史代码风格问题。

## 用户影响

- 直接影响后端开发、联调和启动。
- 不应改变既有接口路径和权限语义。

## 风险

- 兼容性风险：低到中，主要在用户可见文案恢复。
- 回滚风险：低，可按提交回滚。

## 验收标准

- [ ] `backstage-system` 模块可以完成编译。
- [ ] 当前已知阻塞启动的编译错误被消除。
