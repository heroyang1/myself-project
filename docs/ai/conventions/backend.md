# 后端通用约定

## 职责边界

- Controller：入口、参数、权限、响应。
- Service：业务编排、事务、规则判断。
- Mapper：SQL 和数据访问。
- Domain/Entity：数据模型。
- DTO/VO：接口输入输出。
- Client/Integration：外部系统访问。

## 变更要求

- 新增业务规则必须可测试。
- 复杂条件必须有命名方法。
- 涉及多个模块时先写 design。
- 禁止把临时兼容逻辑散落在 Controller。

## 错误处理

- 业务错误返回可理解的错误信息。
- 系统错误记录日志。
- 不把堆栈直接返回给前端。
- 不吞异常。
